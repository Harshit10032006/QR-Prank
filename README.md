# QR-Prank

A fun weekend project where users can generate QR codes and add photos and videos for pranks. Built primarily to practice **Django** and explore the **deployment process**.

## Tech Stack

* **Django** 
* **PostgreSQL** 
* **Cloudinary** — Media storage (image urls)
* **WhiteNoise** — Static file serving
* **Gunicorn** — Run application
* **Render** — Deployment 

# Website visit :
https://qr-prank.onrender.com/
