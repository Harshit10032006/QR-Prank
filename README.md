# QR-Prank

A fun weekend project where users can generate QR codes and add photos and videos for pranks 

## Tech Stack

* **Django** 
* **PostgreSQL** 
* **Cloudinary** — Media storage (image urls)
* **WhiteNoise** — Static file serving
* **Gunicorn** — Run application
* **Render** — Deployment
